# PagePilot Website

The official marketing / landing website for **PagePilot** — an AI-powered Facebook Page automation platform.

## Tech

- Next.js 15 + React 19 + TypeScript + Tailwind CSS
- Lucide icons

## Pages

- `/` — landing page (Hero, Features, How it works, Pricing, CTA, FAQ)
- `/privacy` — Privacy Policy
- `/terms` — Terms of Service
- `/cookies` — Cookie Policy

## Run

```bash
npm install
npm run dev
```

## Deploy

Deploys to Vercel. Set `NEXT_PUBLIC_SITE_URL` if needed.
